# Meta Skills

Instead of having impact on the project, meta skills may impact on the agent system that develops the project.

For example, the [skill-creator](./skill-creator) skill is a skill that creates another skill.

| Skill                            | Focus                                                            | Use When                                                                                        |
| -------------------------------- | ---------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| [skill-creator](./skill-creator) | Creating Agent Skills that follow the Agent Skills specification | A user wants to create, define, package, or validate a reusable skill for a specific capability |
