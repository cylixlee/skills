# Tech Stack Skills

Tech Stack skills are guidelines of languages, frameworks and ecosystems.

For language-agnostic engineering skills, see [common](../common) skills.

| Skill                                          | Focus                                                                             | Use When                                                                                                                                                                      |
| ---------------------------------------------- | --------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [stardew-valley-smapi](./stardew-valley-smapi) | Stardew Valley SMAPI mod creation, debugging, compatibility, and release workflow | Working on SMAPI mods, content packs, manifests, SMAPI logs, Harmony patches, Android compatibility, or mod packaging                                                         |
| [smapi-best-practices](./smapi-best-practices) | Robust SMAPI C# mod architecture and implementation quality                       | Designing, implementing, reviewing, or refactoring SMAPI C# mods where lifecycle, config, content APIs, i18n, multiplayer, diagnostics, migrations, or maintainability matter |
| [rust-pest-parser](./rust-pest-parser)         | Rust parser development using `pest` and `pest_derive`                            | Writing `.pest` grammars, integrating pest parsers in Rust, building ASTs from `Pair`/`Pairs`, handling whitespace/comments, or debugging pest parse behavior                 |
