# Common Skills

Common skills are common engineering skills and are language-agnostic. They often serve as the architectural and engineering principles.

For guidelines of languages, frameworks and ecosystems, see [techstack](../techstack) skills.

| Skill                                                | Focus                                                                                      | Use When                                                                                                                                |
| ---------------------------------------------------- | ------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------- |
| [test-driven-development](./test-driven-development) | Test-first development workflow and testing discipline                                     | Planning features, implementing changes, fixing bugs, or refactoring code where behavior should be verified by tests                    |
| [design-pattern](./design-pattern)                   | Object-oriented design principles, SOLID, layered architecture, and common design patterns | Designing or generating non-trivial maintainable code that needs clear structure, extensibility, dependency management, and testability |
