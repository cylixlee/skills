# Skills

This repo contains my own skills that are used in daily agentic engineering. They can be divided into three categories:

1. **Common skills**
   
   Common skills are common engineering skills and are language-agnostic. They often serve as the architectural and engineering principles.

2. **Tech Stack skills**
   
   Tech Stack skills are guidelines of languages, frameworks and ecosystems.

3. **Meta skills**
   
   Instead of having impact on the project, meta skills may impact on the agent system that develops the project.

Check the individual subdirectories for more information.

> [!NOTE]
>
> Deprecated skills are placed under [.deprecated](./.deprecated) directory. They're not categorized since they will not be supported anymore.
